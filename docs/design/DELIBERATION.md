# Deliberation surface (Council board)

The council board is a nocturnal council chamber: dark navy glass, hairline borders, layered shadows. **Amber** is authority
(the Chair, the decision, primary actions). **Cyan** is participants. **Rose** is disagreement. **Violet** is a revision or a
fixture. Colour never carries meaning alone: every state has an icon and a word. Tokens: the `--cc-*` block in
`docs/design/tokens.css` (mirror: `councilChamber` in `tokens.ts`); `pnpm audit:contrast` checks AA for every pair.
One icon family: Lucide (`packages/web/src/primitives/Icon.tsx`; `LvIcon` is Lucide too). Status is `StatusChip` (icon + word).
The pixel font (Jersey 10) is only for the small "Council board" label.

## Layout (inside the village dock region, 1120 x 548 at 1280x800)
1. Header: name, question, result line, Fixture/Live/Degraded badge, Close. Provider strip below it (one line).
2. **Phase header**: Gather evidence, Debate, Vote, Synthesis (icon, word, Done / Now / Next, `aria-current="step"`).
3. Three columns: **Council** (portrait roster with provider, role, live/degraded/fixture word, state word; A2A handoff
   arrows; ballot matrix; handoff cards) | **What they are saying** (turn cards; toggle to the Handoff timeline) |
   **Decision** (pinned, amber).
4. Under 1060px two columns, under 760px one column.

## Stage to phase

| wire stage                              | phase           |
|-----------------------------------------|-----------------|
| question, delegation, opinions          | Gather evidence |
| critiques                               | Debate          |
| critiques once a ranking has arrived, dissent | Vote      |
| verdict, actions                        | Synthesis       |
| done                                    | all four done   |

Code: `packages/web/src/council/deliberation/phases.ts`.

## Envelope kind to turn type

| envelope kind | turn type | rule |
|---|---|---|
| delegate | Proposal | the Chair proposes who looks at what |
| ask | Evidence | a member asks another for evidence or a fact |
| answer | Revision | the answer replies to a critique |
| answer | Evidence | replies to an ask, or carries a source citation |
| answer | Proposal | otherwise |
| critique | Challenge | disputes a step |
| rank, vote | (Ballot) | not a chat line: the ballot matrix |
| verdict | (Decision) | not a chat line: the pinned decision card |
| status | none | drives the phase header only |

Code: `turn-types.ts` (`KIND_TO_TURN`, `turnTypeOf`). Room transcript lines map `opinion` to Proposal, `question` to Evidence,
`rank` to Ballot, `verdict` to Decision, and a dissent to Challenge.

## Turn card
Portrait (a button), speaker, `to <recipient>`, type badge, `Turn n`, time, `Replying to <speaker>`, position, and citation
chips that open the source viewer. Cards form a keyboard list (Up/Down/Home/End, Enter marks the reply chain).

## Ballot matrix
Rows are options in council order (average rank, then name); columns are voters with portraits; cells are numeric rank badges
(no icons). A cell outlined in rose is a vote that differs from the council order restricted to what that voter ranked. The
legend says so in words. "Self" means voters do not rank themselves; "None" means no ballot for that option.

## Decision card
Outcome, consensus (`Unanimous / Majority / Split, n of m` from the members' final positions), confidence in words,
provenance (sources, provider, model; a fixture says `Scripted fixture`), dissent (who and why, linked to their turn),
missing evidence (decision without a source, members who cite none, members who did not finish), next steps, and actions:
- **Add proof text**: opens a composer (text or a text file). *Ask again* posts to the existing ask API (`startCouncilRun`) with the
  original question plus `Proof I am adding:` and the text, limited to the ask length (600). Off in replays and without a hub.
- **Ask follow-up**: closes the board and drafts `@cubbie Follow-up on council run <id>: ` in the group chat composer
  (`squad:chat-prefill`, handled by the chat dock and the chat page).
- **Send to chat / Add to plan**: the existing action endpoints, applied to every action item of the run.

## A2A handoffs
SVG arrows in the roster gutter between the portraits of sender and receiver (amber when the Chair is on one end). A new handoff
draws in with `stroke-dashoffset` in `--cc-handoff-ms` (200 ms, `cubic-bezier(0.23, 1, 0.32, 1)`) and lights the receiving
card (`transform`). Static in Calm and `prefers-reduced-motion`. A text twin is kept for screen readers.

## Portraits
Chill, Grind, Advisor and Chairman use the animated busts (`CastAvatar`). Every other seat uses a crest generated by
`assets/pixel/composed/scripts/crests.py` from frame 0 of the repo's own village sprites. See `AGENT-UI.md`.
Clicking a portrait calls `openAgentPanel(agentId)`; the board registers the single selected-agent panel
(`BoardFocusPanel`, from `feature/agent-focus-panel`) for it.
