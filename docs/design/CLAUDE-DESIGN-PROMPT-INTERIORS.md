R: Here is my reference: a cozy top-down pixel classroom in the LimeZu Modern Interiors style (tiled floor, desks, shelves, play mats, round tables, plants, a chalkboard, small characters, rooms separated by walls and doorways). Here is my app: screenshots and styles.css of a student-assistant web app, plus design-checklist.md and tokens. The product lives in students' iMessage; the web app is where a student goes to see their study agents and join them. An earlier side-view night village exists; this campus replaces it as the main world.

I: Design "Squad Campus", a walkable top-down indoor campus that is the front door to every agent. Before designing, extend DESIGN.md from INTERIORS-ART.md: tile scale, the interiors palette, daylight, HUD style over bright floors, type and motion. Show 2 directions for the Commons plus one classroom only, then wait for my pick. After I pick, design these, desktop (1280px) first, then phone (390px):

1. Lobby / Commons: spawn point, a shared table for agent messages, doorways to every wing. Top HUD: portrait chips for every agent with state (idle, studying, in a call, waiting for you), zoom buttons, a Calm mode toggle, a "Go to" room menu. Collapsible side panel in my web app's style listing the same agents.
2. Classrooms (one per chapter): chalkboard, teacher desk, rows of desks, a mastery lamp (dim to bright), an expert agent character at its desk. Stepping to the chalkboard opens the quiz as a DOM sheet.
3. Council Room: round table, 3 members plus a chairman. Show the sequence: each member's thought bubble appears independently, bubbles pass between them to rank, the chairman stands for the verdict, a lone red-lined dissenting bubble and a flickering lamp for disagreement.
4. Other rooms, each recognizable from its doorway: Debate Hall (lecterns, tiered seats), Library (shelves, reading nook, citation cards), Cafeteria (Lock-In lobby, long tables), Infirmary (Panic Line, a phone, lit at 2 am), Exam Room (one chair, an examiner), Reception (front desk and a big notice board: the disclosure ledger of shared versus withheld, withheld as black bars). Dimmed until relevant.
5. Join a call: walking up to an agent and pressing "Join call" opens a call panel over the scene: animated pixel portrait, voice waveform, running captions with citations, mute, hand-raise, leave. Group calls show several students standing in the room.
6. Agent mesh: each student agent has a private room with a locked door; others can see it but never enter. When agents negotiate, they carry envelopes through corridors to the shared table; bubbles show only shared fields; a conflict shows a red "!"; an agent waiting for its student's yes stands at its own door with a pulsing ring. When everyone confirms, the trip cutscene plays once and is skippable: agents file out of the front doors, a bus pulls up, the Trip door opens.
7. Replay mode: a "Demo replay" toggle plays scripted events (same visuals); a badge says Replay or Live.
8. Mobile: tap-to-walk on the floor, optional virtual joystick, bottom dock of agent chips, calls and quizzes as full-screen sheets.

S: Style: cozy top-down pixel art at one consistent scale (16px tiles, characters 16x32, whole-pixel positioning, no blurry scaling: image-rendering: pixelated), soft daylight and the Modern Interiors palette (palette-interiors.json), no hard shadows, light cues only at sprite level (lamps, chalkboard glow, optional night tint), in the spirit of my reference image. The campus is the scene; panels, buttons and text around it follow my existing web app's tokens so the two feel like one product. Never use another brand's logo or characters. Use the attached previews as style targets only (do not redraw or redistribute the pack); design with placeholder 16px tiles and the existing 3D set only for small UI chrome. The dark glass HUD must stay readable over the lightest floor. Privacy is part of the design: never show grades, budgets or who is behind; show team progress. Every screen has designed empty, loading, error and "agent offline" states. Plain, friendly student-voice copy; no jargon like "MoE", "PSI" or "mesh". Credits line for all art.

MOTION (follow 08-village-motion.md, the single motion plan; follow it exactly):
- Gate first: every animation gets a frequency (100+/day, tens/day, occasional, rare) and one purpose (feedback, spatial consistency, state indication, preventing a jarring change, explanation, delight). No purpose, no animation.
- Walking is the game, so it is never eased (4-direction, normalized diagonals): constant speed, instant start, 80ms ease-out stop, whole pixels, no camera lag on key input. Delight only in rare moments (the trip cutscene, first arrival in the village).
- Words never move for style: captions, the notice-board ledger, quiz questions and bubbles appear whole and stay at least 1.2s per 20 characters; withheld text is a static black bar. Quiz answers and feedback change colour only (150ms). Nothing repeats faster than once a second except sprite frames. Nothing is a score.
- Tokens, defined once in DESIGN.md and shared by canvas and DOM, no other curves, never ease-in: --ease-out: cubic-bezier(0.23, 1, 0.32, 1) (enter/exit); --ease-in-out: cubic-bezier(0.77, 0, 0.175, 1) (moving on screen); --ease-drawer: cubic-bezier(0.32, 0.72, 0, 1) (panels from an edge). Rare-delight spring only: { duration: 0.5, bounce: 0.2 }.
- Tools: canvas uses spritesheet frames plus tweens on transform and alpha (whole-pixel sprite positions, pixelArt, one atlas per scene, 60fps on a phone). DOM overlays (call, quiz, ledger, HUD) animate only transform and opacity (clip-path for the check draw) with CSS transitions and @starting-style; never transition: all, never scale(0) (enter from scale(0.95) plus opacity 0). UI under 300ms (panels 200-280ms); world animations (bubbles, council sequence, envelopes, room-to-room camera clamps) may run longer. Hover only in (hover: hover) and (pointer: fine).
- Pause the game loop when the tab is hidden and resume without catching up. Nothing flashes more than 3 times a second; no autoplay audio.
- Reduced motion: every animation has a prefers-reduced-motion variant, fewer and gentler, not zero (ambient loops stop, walking becomes teleport-with-fade, bubbles fade without movement, trip cutscene becomes a static card). The "Calm mode" toggle in the HUD applies the same variants.
- Deliver a motion table in DESIGN.md: animation, where (canvas or DOM), frequency, purpose, tool, curve and time, reduced-motion variant.
