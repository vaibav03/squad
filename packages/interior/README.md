# @squad/interior

Top-down indoor campus engine (Phaser 3.90, 16x16 tiles, Tiled JSON). Replaces the side-view village as the walkable world (docs/specs/10-interior-campus.md). The art is behind one manifest indirection, so the licensed LimeZu Modern Interiors pack can drop in locally without touching code.

```ts
import { mountInterior } from '@squad/interior';
const h = mountInterior({ parent, source, onOverlay, assetBase: '/assets' }); // h.destroy(), h.setCalm(), h.overlayClosed(), h.setCamera('room'|'follow')
```

`source` is any `VillageSource` (live SSE or replay). Phaser is imported lazily inside `mountInterior`, so SSR never touches `window`.

## Run

```
pnpm --filter @squad/interior dev            # http://localhost:5191  (?calm  ?camera=follow  ?nostory  ?seed=N)
pnpm --filter @squad/interior test           # unit tests (vitest)
pnpm --filter @squad/interior typecheck
pnpm --filter @squad/interior gen:assets     # regenerate placeholder tileset, props atlas, demo map (deterministic)
pnpm --filter @squad/interior shots [tag]    # Playwright frames -> docs/design/shots/interior-engine/
```

Controls: arrows or WASD walk (diagonals normalised), Enter/Space/E interact, tap or click a floor tile to walk there (A* via easystarjs), tap a character to open its card, tap an interactable to walk to it and activate.

## Layout

- `src/tilemap`: Tiled parse (zod), collision (authored layer + prop footprints + locked doors), `moveAndSlide`.
- `src/nav`: easystarjs pathfinder (sync, 4-way), constant-speed `PathFollower`, goal resolution.
- `src/world`: `RoomRegistry` (rooms, doors, waypoints, interactables, door routing), y-sort depth bands, camera math (follow and room snap), motion curves, seeded rng.
- `src/agents`: `director` (VillageEvent to move/lock/marker commands, pure), interactable to overlay mapping.
- `src/scene`: Phaser scene, actors, HUD (DOM), input. `src/boot`: mount and integer scaler (DPR rule of DESIGN.md 2.3).
- `src/shared`: overlay bridge and a manual source; candidates for a shared package.

## Map contract (Tiled JSON, orthogonal, 16 px, plain-array tile data)

Tile layers `ground`, `wall`, `furniture`, `overhead` (above characters), `collision` (non-zero blocks). Object layers: `rooms` (rect, name=id; props label, kind, snap), `doors` (rect over the 2 doorway tiles; props a, b, locked, prop `door.h|door.v`, spriteX, spriteY), `waypoints` (points; prop room; names like `commons.hearth`, `door.<id>.a|b`), `interactables` (points; label, room, radius, kind), `props` (name = atlas sprite, x,y = sprite bottom-left; y-sorted with characters by base y), `spawns` (`player`, `npc.N`). Prop atlas JSON gives each sprite a tile-aligned `foot` rect that blocks.

## Assets and the licensed pack

Engine code never names a file: `assets/interior/manifest.json` (committed, CC0 placeholder art generated by `scripts/gen-tileset.mjs`) is deep-merged with the gitignored `assets/interior/manifest.local.json`. `scripts/import-modern-interiors.mjs --from <pack> --recipe <recipe.json>` copies chosen files into the gitignored `assets/vendor/modern-interiors/` and writes that local manifest (example recipe: `assets/interior/vendor-recipe.example.json`). The pack's real folder layout and character sheet format are unverified until it is downloaded; the recipe carries frame size, anchor and animation frame indices so a 16x32 6-frame sheet fits without code changes. Credit when active: "World art: Modern Interiors by LimeZu".

## Behaviour notes

Walking is constant speed with an instant start and stop (spec 08 row 3 asks for an 80 ms ease-out stop; not implemented because tile paths stop on a whole pixel, one-line change in `PathFollower`). Calm mode (OS reduced motion or `setCalm`): camera jump-cuts between rooms, NPC wandering off. Door sprites show locked/closed/open; closed doors open when anyone is within 1.75 tiles.
